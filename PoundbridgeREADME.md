POUNDBRIDGE
[ COORD: 26°06′15.2″S 28°03′19.96″E ] // INSTITUTIONAL INFRASTRUCTURE

The digital facade, telemetry dashboard, and lightweight research CMS for the Poundbridge Family Office. The architecture mirrors the structural reality of the firm, built across two strictly isolated naves: Salisminster (the defensive vault) and Burj Al-Jabr (the offensive algorithmic tower).

I. Architectural Philosophy
The repository is designed to reflect the firm's core tenet: Asymmetry.

Salisminster (The Vault): Engineered for generational endurance, operating on timescales of decades to centuries. Represented by weight, stone, and immovable equilibrium.

Burj Al-Jabr (The Tower): Engineered for algorithmic convexity and high-frequency strikes. Represented by steel, kinetic velocity, and millisecond execution loops.

The Merge: The singular joint between the two—a one-way siphon where velocity is converted into stone.

II. Design Language & Aesthetics
The UI/UX merges dark Gothic cathedral verticality with organic, parametric structures inspired by Zaha Hadid. The interface is treated as a Mecha control terminal—cold, precise, and uncompromising, yet structurally beautiful.

Palette: Obsidian Gray (#0a0a0b), Basalt (#131316), Metallic Gold (#c8a35e), and Steel Blue (#7c8f9c).

Typography:

Display / Prose: EB Garamond (Echoing legacy and time)

UI / Structure: Inter (Clean, modern legibility)

Telemetry / Code: JetBrains Mono (Machine execution and data)

Visual Mechanics: Features imperceptible breathing glows on critical nodes (Genesis tab), cinematic blur states for temporal shifting, and dynamic tick-level circuit breaker warnings.

III. Technical Stack
Built for absolute sovereignty and zero external bloat. The system avoids heavy JavaScript frameworks in favor of bare-metal browser native technologies, ensuring rapid load times and infinite shelf-life.

Markup & Styling: Vanilla HTML5 and highly optimized Custom CSS3 (CSS Variables, Flexbox, CSS Grid).

Interactivity: Vanilla ES6 JavaScript.

Data Parsing: mammoth.js (Client-side .docx to HTML conversion for the Principal CMS).

Storage: A dual-layered architecture utilizing articles.json via GitHub Pages CMS for primary deployment, with seamless degradation to Browser localStorage for local offline development.

IV. Core Modules
1. The Temporal Pincer Canvas
An interactive SVG visualization mapping the convergence of time horizons. Features a fluid Apple-style segmented controller that transitions the interface between Milliseconds (Burj Al-Jabr execution), Months (Macro Macro runs), and Millennia (Salisminster generational ballast). Integrates a live JavaScript clock ticking to the second.

2. Principal CMS Terminal
A restricted, client-side publishing interface protected by an authentication gateway.

Capabilities: Draft, edit, and delete technical dispatches.

Ingestion: Native support for uploading .docx files, automatically parsing word processing documents into clean HTML via mammoth.js.

Routing: Dynamically tags and filters dispatches by desk (Offensive vs. Defensive).

3. Secure Transmission Corridor
A segmented contact array for principal and quantitative inquiries. Features liquid morphing transitions to swap context and instructions based on the selected desk, ultimately formatting and routing structured payloads to dedicated encrypted inboxes (principal@poundbridge.co.za or quant@poundbridge.co.za).

V. Local Deployment
No build steps, node modules, or compilers required.

Clone the repository to the local environment.

Serve the root directory using any local web server to bypass CORS restrictions for the Mammoth.js parser.

Bash
python3 -m http.server 8000
Access the terminal at http://localhost:8000.

Principal CMS Access: Terminal access is restricted natively via SHA-256 cryptographic hashing. Passwords are never stored in plain text
